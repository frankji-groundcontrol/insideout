# Design System

The design system's versioned record and its accepted visual sources live
here. [CHANGELOG.md](CHANGELOG.md) is the token-layer version record — it
tracks what changed in the token foundation, primitives, and icon/identity
maps (live Flutter is Cobalt-Neo **1.1.0**) and states the bump contract.
[cobalt/](cobalt/README.md) holds the accepted 2026-09-18 Cobalt lock
screens (light/dark home, ideas, PRD, commit, roadmap) plus the app-icon
candidates — the pre-Neo visual source: read them for hue, type, and
layout, not geometry. The design law itself is
[`DESIGN.md`](../../DESIGN.md), and the live token wiring is described in
[architecture/frontend.md](../architecture/frontend.md).
