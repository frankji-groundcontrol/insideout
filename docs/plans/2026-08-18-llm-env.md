# 2026-08-18 — Replace Anthropic env names with INSIDEOUT_LLM_*

Status: in flight

## Goal

Replace `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, and `AI_MODEL` with
app-owned names. The coach talks to `{INSIDEOUT_LLM_BASE_URL}/messages` or
`{INSIDEOUT_LLM_BASE_URL}/responses`. The operator puts `v1` on the base URL;
the server does not insert `/v1`.

## Locked names

| Old | New |
| --- | --- |
| `ANTHROPIC_BASE_URL` | `INSIDEOUT_LLM_BASE_URL` |
| `ANTHROPIC_AUTH_TOKEN` | `INSIDEOUT_LLM_API_KEY` |
| `AI_MODEL` | `INSIDEOUT_LLM_MODEL` |

New: `INSIDEOUT_LLM_SCHEMA` = `messages` (default) or `responses`.

No aliases. Empty API key still selects the offline template coach.

Defaults: base `https://api.anthropic.com/v1`, model
`claude-sonnet-4-20250514`, schema `messages`.
