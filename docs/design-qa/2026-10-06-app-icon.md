# 2026-10-06 — App icon candidates

The user asked for an app icon, then said:

> The pattern is a bit too simple. Can we add a bit more design to it? Minimalism is great, but it probably needs a little more design sensibility.

## Decision

The user later named the file:

> <repo>/docs/design-system/cobalt/icon-candidates/breakout.svg use this as the logo

`breakout` is the installed icon
([changelog](../changelogs/2026-10-06-app-icon-breakout.md)).
The second round stayed on disk and was not installed.

Before that pick, the first four marks (`breakout`, `pierce`, `shift`,
`seam`) were one square, shifted. A second round was drawn after the
note above. Same cobalt ramp, square corners, transparent ground.

| File | Gesture |
| --- | --- |
| [weave](../design-system/cobalt/icon-candidates/weave.png) | Two square rings; one crossing over, one under |
| [through](../design-system/cobalt/icon-candidates/through.png) | A frame, with a brighter square filling the window and stepping out past the corner |
| [rift](../design-system/cobalt/icon-candidates/rift.png) | One square pulled apart along the diagonal |
| [drop](../design-system/cobalt/icon-candidates/drop.png) | The base of the square stepped down by exactly one stroke |

The other marks stay in the same folder. Each PNG has an SVG master
beside it
([issue](../issues/2026-10-06-app-icon-not-installed.md),
[candidates](../changelogs/2026-10-06-app-icon-candidates.md),
[install](../changelogs/2026-10-06-app-icon-breakout.md),
