# 2026-07-27 — Canonical environment configuration guide

Companion to the same-day [environment hygiene pass](2026-07-27-env-hygiene.md):
that one cleaned the `.env.example` template and added `dev.sh`; this one gives
the variables a single documented home. New
[`docs/usage/environment.md`](../usage/environment.md) is now the source of
truth for every environment variable; the var tables that used to be
duplicated across the usage docs collapse into links to it. No behavior change.

## What changed

- **Created [`docs/usage/environment.md`](../usage/environment.md)** — one
  reference covering the mental model (the root `.env` is a dead file; the Go
  server reads only process env via `os.Getenv`; the two live bridges are
  `dev.sh` and docker-compose's `:?`-guarded `${VAR}` interpolation), every
  variable grouped by consumer (Go backend incl. `GITHUB_TOKEN`, AI provider,
  docker-compose-only host-side ports, the frontend's single
  `NUXT_API_INTERNAL_BASE`), both database setups with the exact
  `.env.example` connection strings, recipes (offline AI, plain-http cookies,
  dev CORS, ports, production), security, and the fail-fast troubleshooting
  strings.
- **Trimmed [`docs/usage/local-development.md`](../usage/local-development.md)**
  — deleted the authoritative var table (moved, not duplicated) in favour of
  the quickstart + `dev.sh` usage + a link; the Offline AI mode subsection
  stays, cross-linked to the guide's recipes.
- **Repointed links:** [`docs/usage/README.md`](../usage/README.md) gains an
  index row for the guide; [`CLAUDE.md`](../../CLAUDE.md) now points its
  one-line environment reference at the guide;
  [`docs/usage/deployment.md`](../usage/deployment.md) opens its env section
  with a pointer to the guide.

## Verification

- Inventory-driven: every variable documented appears in a verified inventory
  of `server/internal/config/config.go`, `server/internal/github/github.go`,
  `docker-compose.yml`, and `app/nuxt.config.ts`, and every inventoried
  variable appears in the guide; the fail-fast error strings were matched
