# 2026-08-18 — LLM env names and messages/responses schema

## What changed

Replaced `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, and `AI_MODEL` with:

| Variable | Role |
| --- | --- |
| `INSIDEOUT_LLM_BASE_URL` | Provider base. Include `/v1` yourself. Default `https://api.anthropic.com/v1`. |
| `INSIDEOUT_LLM_API_KEY` | Auth. Empty still selects the offline template coach. |
| `INSIDEOUT_LLM_MODEL` | Model id. Default `claude-sonnet-4-20250514`. |
| `INSIDEOUT_LLM_SCHEMA` | `messages` (default) or `responses`. |

The server posts to `{base}/messages` or `{base}/responses`. It does not
insert `/v1`. `messages` keeps the Anthropic Messages wire format
(`x-api-key`). `responses` uses the OpenAI Responses wire format
(`Authorization: Bearer`).

No aliases for the old names. Operators must rename local `.env` and
Railway `server` variables.
