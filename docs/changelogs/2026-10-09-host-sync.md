# 2026-10-09 — Three-way sync: GitHub, MBP2, and MBP on one `main`

## What changed

GitHub `main`, MBP2 (the Mac the slices were written on), and MBP (the
second Mac) now point at the same commit, `8a7e9ab`, with the same tree.

| Where | Before | After |
| --- | --- | --- |
| GitHub `main` | `9c572ce` | `8a7e9ab` |
| MBP | `1a8816e`, clean, 3 commits behind GitHub | `8a7e9ab`, clean |
| MBP2 | `a762ca8`: 9 unpushed commits and 121 uncommitted paths (80 modified tracked files; 41 untracked entries holding 64 files) | `8a7e9ab`; only held-out files remain untracked |

The 9 commits MBP2 had never pushed (setup TUI, install skill, hosted-API
default, release pipeline) went out with four new slice commits as one plain
fast-forward, `9c572ce..8a7e9ab`. No force-push and no tags, so the
tag-triggered release workflow did not fire; CI runs on pushes to `main`.
MBP was brought up with `git fetch origin` and `git merge --ff-only`.

## The four slice commits

One task at a time, from explicit path lists (HANDOFF: never `git add .`):

- `0fd171e` deps(client) — `client/pubspec.lock`: five transitive packages
  move to the Flutter 3.44 pins. The old lock came from Flutter 3.47 and
  failed `flutter pub get --enforce-lockfile` under the pinned SDK. Its own
  commit so it reverts alone
  ([lesson](../learning/2026-10-09-lockfile-diff-in-sdk-pins-is-toolchain-drift.md)).
- `a4354c3` feat(client) — the breakout app icon on web, iOS, and Android.
- `185ed46` feat(client) — the block component layer (63 paths). The web
  walk at 1440×900 and 390×844 is still open, so its plan stays in flight.
- `8a7e9ab` docs — the three landings' records, their indexes, HANDOFF.

## Held out and redacted

- Eight files stayed untracked by rule: `.grok/` and `.qoder/` (tool
  scratch and raw agent run journals, which carry local runtime paths) and a
  `.DS_Store`. They are recorded in the local, never-committed manifest
  `.git/info/untracked-manifest.tsv` (path, size, mtime, md5, purpose). That
  manifest did not exist before (finding SEC-09 of the
  [2026-10-04 security review](../review/2026-10-04-multirole/22-security.md)).
- Two docs were redacted before commit: an absolute home path inside a
  verbatim user quote (app-icon design QA) and a tool session id in the
  block-craft plan.
